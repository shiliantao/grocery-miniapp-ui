# 商超小程序设计规范

## 1. 基础画布与字体

- 参考画布：390 × 844。
- 参考字体：MiSans；实际项目使用有相应权限的字体，并提供系统中文字体回退。
- 页面左右安全边距：16。
- 主要标题：18–20，加粗；商品名：13，加粗；正文：12–14；辅助信息通常不小于 10。
- 文本对比和点击区域按实际平台校验，视觉稿中的小字不能直接照搬到无障碍要求更高的场景。

## 2. B 版核心色板

| 用途 | 色值 |
|---|---|
| 主绿 | `#175C3B` |
| 深绿 | `#173B2C` |
| 促销红 | `#F0442E` |
| 鲜黄 | `#FFC847` |
| 暖色页面底色 | `#FBF7EF` |
| 主文字 | `#252821` |
| 次文字 | `#7B7D72` |
| 分隔线 | `#EAE3D7` |
| 浅绿 | `#EAF3E5` |
| 浅促销底 | `#FFF0E7` |

背景可使用轻暖色纹理，但不能影响文字和商品图片识别。用户要求“淡一点”时只微调背景强度，不改其他组件。

## 3. 彩色品类入口

- 首页参考为两行四列，单个彩色圆形底 56 × 56，内部实物图 44 × 44。
- 实物图保持完整、清晰和色彩鲜明，不缩小成小图标，不统一成单色线框。
- 蔬菜、水果、蛋品、水产、粮油、乳品、饮料、日用品分别使用有区分度的浅色底。
- 品类名称居中、加粗，文字与背景有足够对比。
- 分类页可使用更大的实物图，但首页不要因新增楼层而压缩品类入口。

## 4. 限时抢购

- 标题横幅：深绿 `#173B2C`，标题白色加粗，闪电图标和倒计时使用鲜黄 `#FFC847`。
- 右侧设置“全部特价 ›”等明确入口，不能只放没有解释的图标。
- 商品卡参考：174 × 202，图片区 174 × 112，两列排列。
- 商品名、促销价、划线原价和“抢”按钮完整出现；促销价与按钮使用 `#F0442E`。
- 商品图是主要视觉面积，不能为增加文字而缩小图片。

## 5. 热卖精选楼层

- 放在限时抢购下方，可设置“热卖精选 / 新鲜果蔬 / 冻品调料 / 特价专区”等标签。
- 标签栏与限时抢购保持相同促销色体系：浅促销底 `#FFF0E7`、选中态 `#F0442E`、选中文字白色。
- 标签文字建议 12、加粗，避免低对比浅棕文字和过小字号。
- 商品卡排版与限时抢购一致，形成稳定浏览节奏。
- 首页预览可只显示标题栏和商品卡上半部，给纵向滑动留空间；不要为完整展示商品而缩小前面的品类和促销内容。

## 6. 黑金充卡会员

- 卡面主色 `#182720`，边框 `#B99A5E`，主金色文字 `#F4DDAE`，辅助金色 `#D8BC79`。
- 使用细边框、低透明圆形光晕、细分隔线和皇冠图标建立层次，避免大面积刺眼亮黄。
- 等级、余额、有效期、折扣权益有明确层级；余额数字参考 34，加粗。
- 充值金额选中态使用浅金底和金色边框；支付按钮延续深底金字。
- 协议勾选和交易记录必须可见，不为了“高级感”隐藏必要信息。

## 7. 图标与操作

- 会员、优惠券、配送费、支付等入口采用“彩色容器 + 语义图标 + 文字”的组合，不使用一排相同的单色小图标。
- 图标必须与含义相符，点击后有明确反馈；重要操作不能只靠颜色区分状态。
- 底部导航保持首页、分类、购物车、我的四项，选中态同时改变底色、图标和文字。

## 8. 三版差异检查

| 维度 | A 鲜绿自然 | B 鲜采生活市集 | C 邻里速配仓 |
|---|---|---|---|
| 核心感受 | 自然、亲切 | 温润、品质、采购欲 | 紧凑、快速、效率 |
| 商品陈列 | 舒展、清晰 | 大图双列、强促销 | 紧凑列表、快速复购 |
| 信息密度 | 中低 | 中等 | 中高 |
| 背景与形状 | 清爽浅色、自然圆角 | 暖色纹理、大圆角 | 深色信息头、利落分区 |

如果三套页面仅颜色不同，应退回重新设计结构。
